# Autonomous-SOC-Triage-Agent-
An autonomous Tier-2 Security Operations Center (SOC) Triage Agent built with LlamaIndex and powered by a local open-source LLM via Ollama. It parses raw security logs, enriches Indicators of Compromise , correlates SIEM history, consults internal SOC playbooks via RAG , and executes safe containment or ticket escalation.
